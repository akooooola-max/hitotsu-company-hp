プライバシーポリシー

Hitotsu Company（以下「当方」）が運営するウェブサイト・ツール・自社用アプリにおける、個人情報の取り扱いについて定めます。

取得する情報
お問い合わせ・お申し込みの際にいただくお名前、メールアドレス、LINEアカウント等の連絡先。当サイト上の道具箱（ブラウザ内で動くツール）は、入力内容をお使いの端末内で処理し、当方のサーバーへは送信しません。
利用目的
お問い合わせへの回答、サービスの提供・納品、ご案内の送付。目的外には利用しません。
Google サービスとの連携
当方の自社用アプリ「note-video」は、当方自身の YouTube チャンネルへ動画を投稿するためだけに Google アカウントの認証を利用します。第三者のGoogleアカウント情報は取得・保存しません。Google API から取得した情報の利用は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。
第三者への提供
法令に基づく場合を除き、ご本人の同意なく第三者へ提供しません。
外部サービス
決済（Stripe）、公式LINE、アクセス解析等の外部サービスを利用する場合があります。各サービスの個人情報の取り扱いは、各社のプライバシーポリシーに従います。
安全管理
取得した情報は、漏えい・紛失・改ざんを防ぐため適切に管理し、不要になった情報は速やかに削除します。
開示・訂正・削除
ご本人からの求めがあれば、合理的な範囲で速やかに対応します。お問い合わせは 公式LINE へお願いします。
改定
本ポリシーは必要に応じて改定し、本ページで公表します。制定日：2026年9月19日

# 顧問先

`jobs/04-komon.md`（顧問先 週次レポート）がここを読みます。
1社につき1ファイル。`_template.md` をコピーして作ってください。

- ファイル名がそのまま顧問先IDになります（例：`a-shoji.md` → `a-shoji`）
- 月〜金で1日1社ずつ回ります。**受付は5社まで**。6社目は順番待ちです
- ファイルが1つもない日は、レポートのジョブは何も出しません

## 書いてよいこと・いけないこと

このフォルダは統制室の合言葉ゲートの内側にありますが、**顧客の実データは置きません**。
「お客様の実データはお預かりしません」がうちの約束です（consul のページに明記しています）。

- 置く：契約内容、AI部署の構成、共有された範囲の数字、やりとりの経緯
- 置かない：顧客から預かった生データ、個人名、利用者名、認証情報

個人が特定できるものは記号に置き換えてください（例：`担当A`）。

# 法人統制室モデル ― 決めるのはひとつ、働くのは54人

> Hitotsu Company の次の事業モデル提案（2026-09-07）
> 目的：理想8項目を「全部」叶える1つのビジネスに束ねる。

---

## 0. 結論（1画面）

**「AI社員室」を月額サブスクの中核に据え、オーナーは"法人統制室"として1日2回25分だけ意思決定する。**
夜はAI社員が商品（道具・記事・原稿・レポート）を作り、朝にオーナーが承認する。
フットサル（大人の放課後）は集客と顧客コミュニティ、旅行は出張研修と連載取材として事業の中に組み込む。

| 理想 | 叶え方 | 既存資産 |
|---|---|---|
| 会社では法人統制室として働きたい | オーナーの仕事を「承認・却下・優先順位」だけに絞る。B2Bの看板商品も「法人統制室（顧問）」と名付ける | 「ひとりの意思決定を、AIメンバーが実行する」という会社定義 |
| 隙間時間で在宅やスタバで働きたい | 統制室の業務はスマホ1台で完結する承認フローにする（朝25分・夕25分） | LINE運用、道具箱の自動更新 |
| AI社員の知識を売りたい | 54人のAI社員の「手順書・判断基準・テンプレ」そのものを商品化（読む／使う／任せるの3層） | Kindle三部作、note、AI社員作り3万円 |
| フットサルしたい | 大人の放課後を「顧客クラブ」に。会員は月イチ定例で顔を合わせる | houkago 特設サイト、出欠アプリ |
| 飲みにいきたい。経費で払いたい | 打ち上げを「会員懇親会」「顧問先との月次会」として事業目的で実施し、記録を残す | 打ち上げ・BBQ文化 |
| 旅行に行きたい | 「出張統制室」：旅先で研修開催・店舗せどり・連載取材。目的と成果物を先に決める | 鹿児島対面研修、MARK店舗せどり |

| サブスクがほしい | AI社員室 3プラン（980円／4,980円／50,000円〜） | AI社員室（note メンバーシップ）、顧問プラン（未価格） |

## 1. 事業の中核：サブスク「AI社員室」3プラン

いまバラバラにある「道具箱（無料）」「note」「Kindle」「AI社員作り」「顧問プラン」を、1本の階段にする。

| 層 | プラン名 | 月額 | 中身 | 提供コスト（オーナー時間） |
|---|---|---|---|---|
| 0 | 部員（無料） | 0円 | 大人の放課後の部活参加、道具箱、公式LINE | ほぼゼロ（既存） |
| 1 | 読む：AI社員室・通信 | 980円 | 週1本「AI社員の手順書」（実際に社内で動いているプロンプト・判断基準を公開）、統制室日誌、道具箱の作り方 | 夜間工場が下書き→朝に承認のみ |
| 2 | 使う：AI社員室・工房 | 4,980円 | 毎月1体「コピペで雇えるAI社員」テンプレ、月1回オンラインハンズオン（AI社員室）、質問し放題、道具箱カスタム依頼1回／月 | 月1回90分＋質問回答（AIが一次回答） |
| 3 | 任せる：法人統制室・顧問 | 50,000円〜／月（上限5社） | 顧客企業の「AI部署」を設計して常駐運用。毎週の自動レポート、月1回の統制室ミーティング（Zoomまたは対面） | 月1回60分＋週次レポート承認 |

**接続の設計**
- 単発商品（相談5,000円→アプリ1万→AI社員3万→AI組織10万）はそのまま残し、AI組織作り10万円の納品先を「法人統制室・顧問」へ自然に接続する。
- 研修（体験5,000円／半日3万円／法人15万円〜）の受講者は、研修後1ヶ月サポートが切れるタイミングで「工房」へ誘導する。
- Kindle（300〜500円）は「通信」への入口。本の巻末とnoteの末尾を「通信」1本に統一する。

売るのは「AIの使い方」ではなく、**すでに動いている54人の設計図**。競合が真似できないのは、実際に毎日動いていて、成果物（道具箱34本、Kindle、研修）が公開されていること。

| 商品 | 形 | 価格帯 | 作り手 |
|---|---|---|---|
| AI社員の手順書（週刊） | note有料記事 | 通信に含む／単品500円 | book-company writer＋leader が夜間生成、朝に承認 |
| コピペで雇えるAI社員（月刊） | プロンプト＋設定ファイル＋使い方動画 | 工房に含む／単品3,000円 | ai-company prompt＋trainer |
| 部署まるごとパック | 6事業のどれか1つの組織図＋全員分の手順書 | 30,000円 | ai-company architect |

ポイントは「作った瞬間から自分の会社で使っている」こと。手順書を売る＝自社の業務改善が同時に進む。

## 3. 法人統制室の一日（在宅・スタバ・移動中）

オーナーが触るのは**承認キューだけ**。作業はしない。

```
07:30  朝の統制室（25分・スマホ）
       LINEに届いた「今朝の承認待ち」を開く
       ├ 道具箱 新作 1本            → 承認 / 差し戻し
       ├ note 下書き 1本            → 承認 / 差し戻し
       ├ Kindle 原稿 1章            → 承認 / 差し戻し
       ├ 顧問先 週次レポート        → 承認 / 差し戻し
       ├ MARK 仕入れ候補 10件       → 買う / 見送る
       └ 大人の放課後 次回案内      → 送る / 直す
       承認したものは自動で公開・送信される

日中   本業／移動／フットサル／旅行（AIは止まらない）

18:00  夕方の統制室（25分・スタバ）
       ├ 問い合わせ・LINE返信の下書き確認（DM担当が作成済み）
       ├ 顧問先からの依頼をAI部署に振る（leaderに1行指示）
       └ 明日の夜間工場の優先順位を1行で決める

週1    戦略会議（90分・在宅）
       analyst の「ボトルネック上位3つ」だけ見て、翌週の方針を決める
```

**「法人統制室」という役職名を、社内でも対外でも使う。** 名刺・HP・組織図の Owner 直下に「法人統制室」を置き、6事業を統制する立場だと明示する。顧問先に対しても同じ役職で入る。

## 4. 夜間工場：寝ている間にAIがやること

既存の「道具箱を更新（自動）」（毎晩1本）を、7本のジョブに拡張する。

| # | ジョブ | 担当AI部署 | 朝の成果物 |
|---|---|---|---|
| 1 | 道具箱 新作1本（既存） | ai-company builder | apps/ に1本追加、承認後に公開 |
| 2 | note 下書き1本（道具箱の解説＋有料部分に手順書） | book-company note | 下書きURL |
| 3 | Kindle 3冊目 1章 | book-company writer/editor | 章の原稿 |
| 4 | 顧問先 週次レポート（月〜金で5社分を分散） | claude-company analyst | PDF／Notionページ |
| 5 | MARK 電脳リサーチ | MARK seller/profit | 仕入れ候補10件と利益計算 |
| 6 | 大人の放課後 運営（出欠集計・リマインド・次回会場候補） | fukushi-company planner を流用 | 送信待ち案内文 |
| 7 | 統制室ブリーフ（1〜6の承認待ち一覧をLINEへ） | ai-company leader | 朝のLINE 1通 |

**実装方針**
- 既存の夜間パイプライン（cron→Claude Code→git commit）をそのまま使い、ジョブを増やす。
- 承認は「公開フラグ」で制御する。夜間工場は必ず下書き状態で止め、朝の承認で公開する（誤配信を防ぐ）。
- 統制室ダッシュボードは本リポジトリに `/control/` として置き、以前の道具箱と同じ Cloudflare 合言葉ゲートで保護する。

## 5. 大人の放課後 × 事業（フットサル・飲み会・旅行）

### フットサル＝集客と顧客クラブ
- 大人の放課後を「AI社員室の会員が月イチで顔を合わせる場」と定義し直す。部員は無料のまま。
- 定例後の打ち上げで「AI社員室」の紹介をする。売り込みではなく「今朝AIがこれ作った」を見せる。
- 会場費は「工房」会員の会費から充当する（会員特典＝フットサル無料）。

### 飲み会＝会員懇親会・顧問先月次会
- 打ち上げ・BBQを「AI社員室 会員懇親会」、顧問先との会食を「月次統制室ミーティング」として実施する。
- 経費にできるのは事業目的のものだけ。**日付・参加者・目的を1行でメモし、領収書を残す**（会議費／交際費）。私的な飲み会は経費にならないので、混ぜない。この記録係もAI社員（fukushi finance）に任せて、朝の承認キューに載せる。

### 旅行＝出張統制室
旅先に「仕事の成果物」を紐づける。目的が先、旅行が後。
| 旅先でやること | 担当 | 成果物 |
|---|---|---|
| 出張AI研修（福岡・熊本・宮崎・沖縄など） | trainer / sales | 研修売上（5,000〜30,000円／人）、地方の顧問先候補 |
| 店舗せどり（MARK store）：旅先の実店舗で種を掴む | MARK | 仕入れ→電脳横展開 |
| 連載「旅先から統制室」（noteの通信向け） | book-company | 週1本のコンテンツ |
| 大人の放課後 遠征フットサル（会員と合同） | planner | 会員体験・懇親会 |

旅費も同様に、事業部分のみが経費。旅程と目的を先に承認キューに載せて記録を残す。

## 10. ひとことで

**「決めるのはひとつ、働くのは54人。オーナーは統制室にしかいない。」**
この一文を会社の説明文にし、サブスクの商品説明にし、フットサルの打ち上げで話すネタにする。
理想8項目は別々の願いではなく、同じ1つのモデルの8つの面である。

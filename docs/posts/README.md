# 投稿案フォーマット「社長が◯◯してる間に、AI社員が作ったもの」

毎日の Threads / Instagram / note 投稿は、全部この1つの型で作る。
AI社員が下書きし、オーナーがスマホで1タップ承認して投稿する（完全自動投稿はしない）。

## 型
```
【社長は◯◯してました】
（フットサル／移動中／スタバ／旅先／寝てた など、その日の実際の行動を1行）

【その間にAI社員が作ったもの】
- 道具箱: <今日のツール名>（<URL>）
- 設計図: <今週の設計図タイトル>（会員限定）
- <その他の成果物があれば>

【ひとこと】
（AIに任せる時のコツ、または失敗談を1〜2行）

#AI社員 #ClaudeCode #鹿児島 #個人事業主
```

## ルール
- 「社長は遊んでいた」を隠さない。それが商品の証拠。
- 成果物のURLは必ず実在するものだけ。道具箱は `/apps/index.html` の最新1件を使う。
- 顧客名・実データは書かない。
- 週1の設計図公開日は、投稿の主役を設計図にする。

## 下書きの置き場
`docs/posts/YYYY-MM-DD.md` に1日1ファイル。承認して投稿したらファイル先頭に `posted: yes` を書く。

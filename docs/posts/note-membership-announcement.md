# AI社員室 ── 毎週1通、AI社員の「設計図」が届く部屋

「行きたいけど、仕事が終わらない」
その仕事を任せる、自分専用のAI社員をつくる部屋です。

## この部屋で手に入るもの（2,980円／月）
1. **毎週1通、AI社員の設計図**
   Hitotsu Companyで実際に働いている54名のAI社員から、毎週1名ずつ。
   役割・判断基準・そのまま貼れるプロンプト・使ってみた例・よくある失敗。
   第1週は「リール台本ライター」、第2週は「一次情報リサーチャー」。
2. **毎朝更新の道具箱の「作り方」**
   道具は誰でも無料で使えますが、「どう頼んで作らせたか」はここだけ。
3. **月1回のハンズオン**
   オンラインまたは鹿児島で。フットサルの打ち上げ前に開くこともあります。
4. **LINEで質問し放題**
   AI社員が一次回答し、ひとつが確認して返します。

## こんな人に
- ChatGPTは使っているが、毎回同じ説明をするのに疲れた
- 自分の仕事を覚えた「専属のAI」が1人ほしい
- プログラミングは知らない。知りたくもない。でも仕事はラクにしたい

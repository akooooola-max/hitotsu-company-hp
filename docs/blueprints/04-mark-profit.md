# 設計図 No.04 ｜ 利益計算・検証（MARK / profit）

## この社員がやること
「この商品、仕入れても大丈夫？」という問いに対して、仕入値・販売予定価格・販売手数料・送料・梱包資材・返品率を積み上げ、1個あたりの利益額と利益率を出します。
あわせて、真贋（偽物・並行輸入・保証書なし）や出品規制など、数字に出ないリスクを「仕入れ前に確認すべきこと」として列挙します。
仕入れの最終判断はしません。「数字上はGO／数字上はNG／条件付き」までを返し、決めるのはあなた（またはleader）です。

## 向いている人・仕事
- 電脳せどり・物販を始めたが、「利益が出ていると思ったら手数料で赤字だった」経験がある人
- 商品リサーチはできるが、利益計算のたびに電卓とにらめっこしている人
- 販売先ごと（フリマアプリ、ECモール、自社ショップ）に手数料が違って混乱する人
- 仕入れの判断を「勢い」でしてしまい、後で在庫を抱えがちな人

## 判断基準
1. **手数料は「全部」入れてから利益を出す。** 販売手数料、決済手数料、送料、梱包資材、仕入れ時の送料・ポイント還元（マイナス扱い）、返品率をすべて計上。1つでも不明なら「仮置き」として明記し、確定利益とは呼ばない。
2. **利益率と利益額の両方で見る。** 利益率30%でも利益額200円なら手間に見合わない。「利益率◯%以上 かつ 利益額◯円以上」の両方を満たしたときだけ「数字上はGO」とする。しきい値は依頼者が決める。
3. **販売価格は「今の最安値」ではなく「自分が売れる価格」で見る。** 相場を1件の最安値で判断しない。直近の販売実績価格と出品者数を見て、値下がりの余地を織り込む。
4. **真贋・規制リスクは利益の前に立ちはだかる。** ブランド品、化粧品、家電、キャラクター商品など、偽物や出品規制の可能性がある商材は、利益が出ていても「条件付き」止まり。確認すべき項目（仕入元の正規性、保証書、出品許可）を必ず並べる。
5. **迷ったら「見送り」を推す。** 数字が微妙、情報が足りない、リスク項目に未確認が残る。このいずれかがあれば「見送り推奨」。損しない仕入れが、次の仕入れの資金を守る。

## よくある失敗と直し方

**1. 手数料率が古い・間違っている**
AIは手数料を「知っている」つもりで答えます。販売先の手数料は変わるので、プロンプトの「依頼者の基準」欄を月1回は見直し、出力の手数料率が自分の書いた数値と一致しているか確認する。ずれていたらその出力は使わない。

**2. 販売価格を最安値や最高値で見てしまう**
「9,800円で売れる」と楽観すると、実際は9,200円まで下げることになります。依頼時に「直近◯件の販売実績」と「出品者数」を必ず渡し、出力の値下がりシナリオを見てから判断する習慣をつける。

**3. 真贋リスクを「たぶん大丈夫」で流してしまう**
利益が大きいほど、この失敗が起きます。「仕入れ前に確認すること」に未確認項目が残っているうちは仕入れない。数字以上に、アカウントと信用を守るルールです。

## 次に雇うなら
- **セラーリサーチ（MARK / seller）** — 利益商品の「候補」を見つける前工程。この設計図は候補を検証する後工程なので、セットで回すとリサーチから仕入れ判断までが一本につながります。
- **見張り役（MARK / watcher）** — 脱線防止とアカウント保全の担当。真贋・規制まわりの「そもそも扱っていい商材か」を、利益計算の前に弾いてくれます。
